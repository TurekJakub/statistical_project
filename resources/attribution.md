# Attribution

This file serves to attribute rightful creators and owners of data, that are used by this project, but are neither created nor owned by it.

## Team performance statistics

All team statistics data inside `playoffs` and `regular` subdirectories of this directory are sourced from [Hockey-Reference](https://www.hockey-reference.com/)

## Tax burden data

Average tax burden data for individual teams inside `tax_burden.html` are sourced from PuckPedia [NHL Tax calculator](https://puckpedia.com/tax-calculator). Content of mentioned file is just slightly cleaned html table (non data elements were manually removed) generated by PuckPedia calculator for annual salary of three millions dollars.
